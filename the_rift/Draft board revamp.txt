def draw_cut_rect(dl, x1, y1, x2, y2, cut=10, fill=None, color=None, thickness=1):
    """Rectangle with 45-deg cuts at top-right and bottom-left corners.
    Hand-built via draw_polygon to support hardware AA."""
    pts = [(x1, y1), (x2 - cut, y1), (x2, y1 + cut),
           (x2, y2), (x1 + cut, y2), (x1, y2 - cut)]
    if fill:
        dpg.draw_polygon(pts, fill=fill, color=(0,0,0,0), parent=dl)
    if color:
        # Close polygon outline manually so we don't double-trace
        for i in range(len(pts)):
            a, b = pts[i], pts[(i+1) % len(pts)]
            dpg.draw_line(a, b, color=color, thickness=thickness, parent=dl)

5. ANIMATION SYSTEM — "THEATRICAL"
The existing tween system (core/animations.py) is great for one-shots (state changes) but the cyberpunk goal requires ambient motion. Almost all of this should be render-time sine/triangle waves keyed on time.monotonic(), not Tween-driven — they're stateless and free.

def _ken_burns_xform(champ_name, base_w, base_h):
    """Return (sx, sy, dx, dy) for a splash-image at this moment."""
    seed = hash(champ_name)
    t = (time.monotonic() / 12.0) % 1.0
    phase = math.sin(t * math.pi * 2 + (seed % 100))
    scale = 1.04 + 0.04 * (0.5 + 0.5 * phase)
    dx = (seed % 21 - 10) * phase
    dy = ((seed // 7) % 11 - 5) * phase
    return scale, dx, dy

6. SCANLINE / GRID BACKGROUND TREATMENT
Full-screen scanline overlay
Cheapest viable: every 4 pixels, a faint horizontal line, animated to scroll downward at ~30 px/s.

def draw_scanlines(dl, x, y, w, h, color=(140, 200, 240), alpha=14, spacing=4, speed=30):
    drift = int((time.monotonic() * speed) % spacing)
    col = (*color[:3], alpha)
    for line_y in range(y - spacing, y + h + spacing, spacing):
        ly = line_y + drift
        if ly < y or ly > y + h: continue
        dpg.draw_line((x, ly), (x + w, ly), color=col, thickness=1, parent=dl)
At 1080px viewport height with spacing=4, that's ~270 lines per frame. At 16ms budget, this is fine — DPG can comfortably push thousands of draw_line calls per frame on modest GPUs. draw_polygon is the most expensive primitive. Corner-cut rects are polygons, so multiply: ~80 cut rects × 1 = fine. ~250 cut rects × 1 = starts to matter. Stay under ~200 polygons per frame.

7.3 Splash art
Ddragon splash URL pattern: https://ddragon.leagueoflegends.com/cdn/img/champion/splash/{id}_0.jpg — 1215×717, JPEG, typical size 80-180 KB. Loading splash:

Per-champion cost: 80-180 KB downloaded once + ~3.5 MB RAM after decode (1215×717×4 bytes for RGBA).
All 170 champions cached on disk: ~25 MB (acceptable; same order as existing champion_cache/ icons).
All 170 in DPG texture memory: 170 × 3.5 MB = ~600 MB GPU memory. Not acceptable.
Solution: cache to disk eagerly, register textures lazily and evict. Maintain a small DPG-registered set (only the currently displayed splash + ~3 recent ones). When TOP CALL changes:

Check if splash texture for new champ is registered → if yes, use it.
If not, check disk cache → if present, decode + register, evict oldest if registered count > 4.
If not on disk, kick off requests.get in a daemon thread; show fallback (current portrait, full-card, no splash) until ready.
Build a new the_rift/data/splash_art.py mirroring the structure of champion_icons.py but with this eviction logic. ~200 LOC.

7.4 Accessibility
Reduce-motion setting. A reduce_motion: bool flag in config disables: scanlines, ambient pulses, particle drift, holographic flicker, ken-burns, marching dashes. Keep: typewriter (informative), confidence bar tweens, TOP CALL slide-in. The CALM MODE toggle and the setting can share this flag.
High-contrast option. Some users find low-alpha gridlines visually noisy. Add a cyber_intensity: float config knob (0.0 = no scanline/grid, 0.5 = current proposal, 1.0 = double alpha). Default 0.5.
Color-blind palette consideration. Cyan + magenta is already a deuteranopia-safe pair. The amber/term_green/alert_red trio is the concern — make sure cohesion warnings (amb) and exploits (term_g) are not the only differentiating cue (the sigils ! and + carry the signal too — keep them).
